# 🔥 Fuego Maya — Restaurant Management & POS App
*(En desarrollo)*

**Fuego Maya** es un sistema integral de punto de venta (POS) y gestión operativa para restaurantes de cocina regional. Diseñado para optimizar la coordinación entre salón, caja y administración mediante interfaces adaptadas por perfil de usuario.

## 💡 Características Clave

- **Control de Acceso por Roles:** Interfaces personalizadas para Administrador, Cajero y Mesero.
- **Toma de Pedidos Móvil:** Interfaz táctil para tabletas con envío directo de comandas a caja y cocina.
- **Mapa de Mesas Interactivo:** Control visual de ocupación (disponible, ocupada, reservada) en tiempo real.
- **Gestión de Inventario:** Panel de control de stock e insumos de cocina.
- **Identidad Visual:** Paleta cálida inspirada en la cultura maya (terracota, naranja y café profundo).
